# Logo Feltöltési Útmutató / Logo Upload Guide (SENEAR & JUNEAR)

Ez a mappa szolgál a két termék kártyájának (csempéjének) jobb felső sarkában megjelenő **kerekített logóknak**.

This folder is designated for the circular product logos appearing in the top-right corner of each product tile.

---

## 📁 Mappa elérési útja / Target Directory:
```bash
public/logos/
```

---

## 🏷️ Fájlnevek / File Names:

### 1. SENEAR termék logója:
* **Elsődleges fájlnév:** `senear-logo.png`
* **Teljes elérési út:** `public/logos/senear-logo.png`
* *(Támogatott egyéb formátumok is:* `senear-logo.svg`, `senear-logo.jpg`, `senear-logo.webp`*)*

### 2. JUNEAR termék logója:
* **Elsődleges fájlnév:** `junear-logo.png`
* **Teljes elérési út:** `public/logos/junear-logo.png`
* *(Támogatott egyéb formátumok is:* `junear-logo.svg`, `junear-logo.jpg`, `junear-logo.webp`*)*

---

## 📐 Ajánlott méret és formátum / Recommended Dimensions & Specs:
* **Alak:** Négyzetes arányú kép (1:1), pl. **512x512 px**, **256x256 px** vagy **128x128 px** (a weboldal automatikusan kör alakú maszkba és finom arany-bronz szegélybe illeszti).
* **Háttér:** Átlátszó háttér (transzparens PNG vagy SVG) ajánlott a legszebb eredményért, de fehér vagy színes hátterű kép is tökéletesen mutat a kör alakú keretben.
* **Fallback:** Amíg nem töltesz fel képet, a weboldal automatikusan egy elegáns, prémium ikonos helykitöltőt jelenít meg a logó nevével.
